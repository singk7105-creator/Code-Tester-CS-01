# BCKP Official Website

## Included
- Responsive bilingual (Hindi/English) public website
- Home page and secondary pages
- Mobile navigation, sticky header, back-to-top
- Demo admin login and localStorage-based demo dashboard
- JSON starter data files

## Setup
1. Extract the ZIP.
2. Put the supplied organisation logo at `assets/logo.png`.
3. Open `index.html` in a browser or deploy the folder to GitHub Pages/Vercel.

## Demo admin (NOT FOR LIVE SECURITY)
- URL: `admin/login.html`
- Email: `demo@bckp.local`
- Password: `BCKP-DEMO-ONLY`

This demo login is client-side and is not secure. Dashboard changes are stored only in that browser's localStorage and do not publish to visitors or sync across devices. Before using a real public admin panel, integrate server-side authentication, authorisation and a database (for example, a secured backend service). Do not use the demo credentials on a live production website.

## Customisation
Replace placeholder contact details and add only verified organisational information, team members, photos and social links.
